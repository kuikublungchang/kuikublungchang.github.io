นโยบายความเป็นส่วนตัว

lungchang-autopost · มีผลตั้งแต่ 28 ตุลาคม 2569

หน้าแรกข้อกำหนดการใช้งาน

lungchang-autopost (“แอป”) เป็นเครื่องมือส่วนตัวของเจ้าของช่อง “คุยกับลุงช่าง” ใช้เผยแพร่คลิปที่ช่องผลิตเองลงบัญชีของช่องเอง ผู้ใช้แอปมีเพียงเจ้าของช่องคนเดียว นโยบายนี้อธิบายข้อมูลที่แอปเข้าถึงและวิธีดูแลข้อมูลนั้น

ข้อมูลที่แอปเข้าถึง

  • Google / YouTube: สิทธิ์อัปโหลดวิดีโอ (youtube.upload) และอ่านข้อมูลพื้นฐานของช่อง (youtube.readonly) เพื่อยืนยันว่าเชื่อมกับช่องที่ถูกต้อง
  • Facebook / Instagram: รายชื่อเพจที่เจ้าของดูแล โทเคนของเพจ และบัญชี Instagram ที่ผูกกับเพจ เพื่อเผยแพร่ Reels
  • TikTok: ข้อมูลพื้นฐานของบัญชี (user.info.basic) และสิทธิ์ส่งวิดีโอเข้ากล่องร่าง (video.upload)

แอปไม่เข้าถึงข้อมูลผู้ชม ความคิดเห็น ข้อความ รายชื่อผู้ติดตาม หรือข้อมูลส่วนบุคคลของผู้ใช้รายอื่น

การใช้ข้อมูล

ใช้เพื่ออัปโหลดและตั้งเวลาเผยแพร่คลิปของช่อง และบันทึกลิงก์/เวลาที่โพสต์ลงไฟล์บนคอมพิวเตอร์ของเจ้าของช่องเท่านั้น ไม่ใช้เพื่อโฆษณา ไม่วิเคราะห์พฤติกรรม และไม่ขายหรือแบ่งปันให้บุคคลที่สาม

การจัดเก็บและความปลอดภัย

โทเคนการเข้าถึงเก็บไว้ในตัวแปรสภาพแวดล้อมของผู้ใช้ Windows บนคอมพิวเตอร์ของเจ้าของช่อง ไม่ถูกส่งหรือเก็บบนเซิร์ฟเวอร์ใด ข้อมูลส่งตรงระหว่างคอมพิวเตอร์ของเจ้าของกับ API ทางการของแต่ละแพลตฟอร์มผ่าน HTTPS

การลบข้อมูลและการถอนสิทธิ์

เจ้าของบัญชีถอนสิทธิ์ได้ทุกเมื่อที่ Google Account permissions, การตั้งค่า Facebook → Business integrations และ TikTok → Settings → Security → Manage app permissions เมื่อลบตัวแปรสภาพแวดล้อมบนคอมพิวเตอร์ ข้อมูลโทเคนทั้งหมดจะหายไป แอปไม่มีสำเนาอื่น

บริการของ Google และ YouTube

แอปใช้ YouTube API Services การใช้งานจึงอยู่ภายใต้ ข้อกำหนดการให้บริการของ YouTube และ นโยบายความเป็นส่วนตัวของ Google การใช้และส่งต่อข้อมูลที่ได้รับจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use
